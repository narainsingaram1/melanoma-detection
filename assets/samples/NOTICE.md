# Sample images

One image per class from the **held-out test split** (never used for training or model selection),
taken from the HAM10000 dataset:

Tschandl, P., Rosendahl, C. & Kittler, H. *The HAM10000 dataset, a large collection of multi-source
dermatoscopic images of common pigmented skin lesions.* Sci. Data 5, 180161 (2018).
doi:10.1038/sdata.2018.161. Licensed under CC BY-NC 4.0 (https://creativecommons.org/licenses/by-nc/4.0/).
File names keep the original ISIC image IDs.
